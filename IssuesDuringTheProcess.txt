Regarding filters, I wasn’t sure what was better: creating a constant with the genres on the frontend, or creating a new endpoint to return a JSON with all the genre data. In the end, I created the constant on the backend to generate a new endpoint, since when scaling a project it's always easier to add new information to the database, and that way there’s no hardcoded data on the frontend.
